After GitHub Pages finishes deploying:
1. Open the live site over HTTPS on your phone.
2. Refresh it once.
3. Open Settings in Duck Budget and tap “Install / Add to Home Screen”.
4. Android/Chrome may show a native Install prompt.
5. iPhone/iPad uses the browser Share menu > Add to Home Screen. That is the normal installation route for a web app on iOS.

Once installed, Duck Budget should open in a standalone app-style window and work offline after it has been loaded once.
