OPTIONAL DUCK CATEGORY ASSETS

The app works without these files and shows emoji fallbacks until you add them.
If you want your game ducks to appear as the category icons, place PNGs in this
images folder using these filenames:

  gentleman-duck.png  = Income
  lemon-duck.png      = Bills
  burger-duck.png     = Food
  party-duck.png      = Fun
  tiny-ducks.png      = Shopping / Other
  angel-duck.png      = Savings
  devil-duck.png      = Debt

Transparent PNGs work best.

Your custom home-screen app icon should be named:
  budgeticon.png
and placed NEXT TO index.html (not inside this images folder).
