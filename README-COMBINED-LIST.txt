DUCK BUDGET — COMBINED SHOPPING LIST + SAVED OTHER ESSENTIALS

WHAT CHANGED
- Shopping now has two subviews: Meal plan and Grocery list (the separate Other tab is gone).
- All ingredient items with matching names, ignoring case and extra spaces, appear as ONE grocery entry marked ×2, ×3 and so on.
- The combined price is the SUM of the original estimated prices; weekly totals do not double-add entries, nor does grouping change your recipes.
- A combined checkbox checks/unchecks all underlying ingredient/Other items for the current week. Partially checked existing entries show a mixed checkbox state.
- If the same named item occurs in meals and Other, it appears once in the meal ingredients section; manage the underlying Other entry using the Manage button.
- Other essentials now live inside Grocery list, with + Item, Saved, and Manage buttons.
- When adding an Other item, optionally check Save for later so you can reuse it in any future week. You can also save an Other item without adding it this week.
- Saved Other items support Add to this week, Edit, and Delete. Editing templates does not change items already used in earlier weeks.
- Existing weekly budgets, meal plans, shopping lists, checkmarks, and saved recipes are preserved. Saved Other items are included in JSON exports/imports.
- All other Duck Budget tabs and Duckie Days art are preserved.

HOW TO INSTALL
1. In Duck Budget Settings, export a backup first.
2. Extract the downloaded ZIP file. Do NOT upload the ZIP itself.
3. Select its CONTENTS (index.html, service-worker.js, images/, manifest.json, etc.) and upload them to the ROOT of the GitHub repository.
4. Commit changes, wait for GitHub Pages deployment, then refresh the installed site/app.

DATA NOTE
Shopping plans are estimates and do NOT automatically deduct money from your balance. Data remains local to your browser.
