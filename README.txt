  index.html
  manifest.json
  budgeticon.png  <-- your 500x500 icon
  images/          <-- optional category duck assets

WHAT THIS VERSION DOES
- Phone-first Home hub with Safe to Spend
- Paycheck Planner with category budgets
- Bills with due days and Mark Paid
- Bill suggestions for the current paycheck window
- Transactions: Expense, Income, Savings, Debt
- Savings goals and progress
- Debt trackers (Settings gear)
- Local-only browser storage
- Export/import JSON backups
- Custom app icon support

IMPORTANT ABOUT YOUR DATA
All budget data is stored in localStorage in the browser on that device.
GitHub only hosts the app files. Your transactions are NOT written into the repo.

Export a backup before:
- clearing Safari/Chrome website data
- changing the GitHub Pages URL/repository
- changing phones

APP ICON
Put your 500x500 budgeticon.png in the same folder as index.html.
That is enough for this starter. We can make dedicated Apple/Android icon sizes
later from your finished icon if you upload it here.

CATEGORY DUCKS
See images/README.txt. They are optional; emoji appear until the PNGs are added.

ADDING TO AN IPHONE HOME SCREEN
1. Open the GitHub Pages site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. The app will launch in a standalone-style window and use budgeticon.png.
