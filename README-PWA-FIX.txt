After GitHub Pages finishes deploying:
1. In Android Chrome, close every Duck Budget tab.
2. Open Chrome > Settings > Site settings > All sites.
3. Find peachiepeeps.github.io and clear/reset its stored site data if Duck Budget was previously cached.
4. Reopen https://peachiepeeps.github.io/duck-budget/
5. Reload once.
6. Open Chrome's three-dot menu. Duck Budget should now be offered as an installable app rather than only a generic shortcut.

Your budgeting data is local browser data, so EXPORT A BACKUP before clearing site data if you have already entered anything important.
