DUCK BUDGET — WEEKLY SHOPPING + MEAL PLANNING UPDATE

WHAT'S NEW
- Home page button: Shopping & Meals
- Separate Sunday-to-Saturday weekly meal planning screen
- Set/edit a grocery budget for any week
- Previous / next week buttons and a jump back to this week
- Open each day, add meals (breakfast, lunch, dinner, or anything you name)
- Add items/ingredients with their own estimated costs beneath each meal
- Edit or delete meals, items, and prices
- Automatic day and week totals, plus a remaining/over-budget indicator
- Grocery checklist built from all added items, with saved checkmarks

DATA & COMPATIBILITY
- Existing income, bills, transactions, savings, debt, and paycheck plans are preserved.
- Shopping weeks are included in the existing JSON Export/Import Backup.
- All data is saved locally in your browser. No external accounts or server used.
- Shopping estimates do not create real transactions or deduct from the paycheck budget.
  To track money you actually spent, add a regular Food expense separately.
- If an ingredient appears in multiple meals, each entry counts toward the weekly
  estimated total. You can use one item entry to represent a shared grocery purchase.

INSTALL / UPDATE ON GITHUB PAGES
1. Back up your existing data in Duck Budget (Settings > Export backup).
2. Unzip this package and upload the files inside duck-budget-main/ to the ROOT
   of your existing GitHub Pages repository, replacing the old index.html.
3. Keep the original site URL / browser profile to retain existing local data.
4. Refresh the app and open Shopping & Meals from Home.

TIP: When starting a new week, the new budget and meals begin empty; old weeks
remain available with the arrow controls.
