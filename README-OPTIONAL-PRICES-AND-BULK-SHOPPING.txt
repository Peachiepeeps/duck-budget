Duck Budget — Optional Prices + Shopping List Ordering and Bulk Actions

Shopping List
- New item prices are optional. Leave the price blank while shopping.
- Unknown prices display as Price not set and do not count as known $0.
- Enter a price later with Edit. Totals show a warning while prices are missing.
- Use ↑ and ↓ on a list row to move it; matching duplicate entries move together.
- Tap Select items to remove. The checkboxes switch from bought/check-off mode to removal selection. Select all, Remove selected, or Cancel. Confirmation is required to remove.
- Removing from the current week does NOT delete saved templates or entries in other weeks.

Saved Shopping Items
- Open Saved from the Shopping List. Select multiple items or Select all, then Add selected in one action.
- Add selected skips names that are already on this week's list to prevent accidental duplicate purchases. For extra quantities, use the individual Add button.
- Saved item selection can also delete multiple saved items after confirmation. Current and previous shopping lists are unaffected.
- Prices may also be blank on saved items and stay blank when re-added.

No changes to DailyPay, Bills, or Meal Plan behavior. All planning data stays local to the device.

GitHub installation: Export a backup, extract this ZIP, then upload its CONTENTS to the root of your existing GitHub Pages repository. Do not upload the ZIP itself or its enclosing folder.
